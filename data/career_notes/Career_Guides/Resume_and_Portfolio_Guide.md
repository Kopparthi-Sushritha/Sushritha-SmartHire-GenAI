# Resume and Portfolio Guide

## 1. Purpose

A resume communicates relevant skills and evidence of capability. A portfolio provides deeper proof through projects, code, demos, and documentation.

## 2. Recommended Resume Structure

For a fresher:

1. Name and contact
2. Professional summary
3. Technical skills
4. Projects
5. Education
6. Certifications
7. Achievements
8. Links

Keep the most relevant information easy to find.

## 3. Professional Summary

A good summary should communicate:

- Current career direction
- Main technical strengths
- Relevant project experience
- Target role

Avoid generic statements that provide no evidence.

## 4. Technical Skills

Organize skills into categories.

Example:

### Programming

- Python
- Java
- JavaScript

### Web

- HTML
- CSS
- React
- FastAPI

### Data/AI

- SQL
- pandas
- scikit-learn
- PyTorch
- RAG

### Tools

- Git
- GitHub
- Docker

Only list technologies you can discuss in an interview.

## 5. Project Section

For every strong project include:

- Project name
- Problem
- Technology
- Implementation
- Result
- Link

A useful structure is:

**Built X using Y to solve Z, implementing A and B, resulting in C.**

Do not invent numerical results.

## 6. Project Selection

Choose projects that demonstrate the target role.

### Full Stack

Show:

- Frontend
- Backend
- Database
- Authentication
- Deployment

### Data Analyst

Show:

- SQL
- Data cleaning
- Dashboard
- Business insights

### ML Engineer

Show:

- Data pipeline
- Model
- Evaluation
- API
- Deployment

### GenAI

Show:

- LLM
- Embeddings
- RAG
- Evaluation
- API
- Deployment

## 7. GitHub Portfolio

Each repository should contain:

- README
- Problem statement
- Features
- Architecture
- Tech stack
- Setup instructions
- Usage
- Screenshots
- Results
- Testing
- Limitations
- Future improvements

Keep the repository clean.

Recommended:

## Usage

## API

## Results

## Screenshots

## Limitations

## Future Improvements

## License

## 9. Portfolio Website

A simple portfolio can contain:

- About
- Skills
- Projects
- Resume
- GitHub
- Contact

Keep navigation simple.

## 10. ATS-Friendly Resume

Use:

- Standard headings
- Clear text
- Consistent formatting
- Relevant keywords
- Simple layout

Avoid:

- Excessive graphics
- Important information inside images
- Unreadable fonts
- Keyword stuffing

## 11. Resume Customization

For every relevant job:

1. Read the job description.
2. Identify required skills.
3. Prioritize matching skills.
4. Reorder relevant projects.
5. Use accurate terminology.
6. Remove unrelated information where space is limited.

Never claim experience you do not have.

## 12. Quantifying Projects

Use numbers only when they are real.

Good:

- Processed 50,000 records.
- Built 12 API endpoints.
- Reduced response time from X to Y based on measured tests.

Avoid fabricated metrics.

## 13. Certificates

Certificates can support learning, but they should not replace projects.

Prioritize:

- Recognized learning programs
- Practical coursework
- Relevant certifications

## 14. LinkedIn/Profile

Keep consistent:

- Headline
- About section
- Skills
- Projects
- Education
- Certifications
- GitHub links

## 15. Portfolio Quality Checklist

- [ ] Clear target role
- [ ] Relevant skills
- [ ] 3–5 strong projects
- [ ] Working code
- [ ] Good README
- [ ] Screenshots/demos where useful
- [ ] Deployment where practical
- [ ] No copied code without understanding
- [ ] No fake metrics
- [ ] Consistent resume and GitHub

## 16. Example Portfolio Strategy

For an aspiring AI Engineer:

Project 1:
Classical ML prediction system.

Project 2:
Deep-learning application.

Project 3:
RAG application using embeddings and a vector database.

Project 4:
AI agent using tools.

Project 5:
Deployed production-style AI application with API, Docker, monitoring, and evaluation.

## 17. Common Resume Mistakes

Avoid:

- Long paragraphs
- Unrelated skills
- Fake experience
- Repeated keywords
- Generic objectives
- Poor grammar
- Broken links
- Unexplained projects
- Listing every course ever taken

- [ ] Clear target role
- [ ] Strong summary
- [ ] Relevant skills
- [ ] Strong project bullets
- [ ] Education
- [ ] Relevant certifications
- [ ] GitHub link
- [ ] Portfolio link
- [ ] No spelling errors
- [ ] No fake claims
- [ ] Resume tested against target job descriptions
