# Data Analyst Role Guide

## 1. What Is a Data Analyst?

A Data Analyst collects, cleans, analyzes, visualizes, and communicates data to support business and operational decisions.

The role commonly combines:

- SQL
- Excel or spreadsheets
- Statistics
- Data visualization
- Business understanding
- Reporting
- Dashboard development
- Data quality

## 2. Core Skill Areas

### A. Excel and Spreadsheets

Learn:

- Formulas
- SUM, AVERAGE, COUNT
- IF
- COUNTIF and COUNTIFS
- SUMIF and SUMIFS
- XLOOKUP
- INDEX/MATCH
- Text functions
- Date functions
- Conditional formatting
- Data validation
- Pivot tables
- Charts
- Power Query basics

### B. SQL

Learn:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- DISTINCT
- CASE
- Aggregate functions
- JOINs
- Subqueries
- CTEs
- Window functions
- Date operations
- NULL handling

Important concepts:

- Primary keys
- Foreign keys
- Indexes
- Normalization
- Query performance

### C. Statistics

Understand:

- Mean
- Median
- Mode
- Variance
- Standard deviation
- Percentiles
- Distributions
- Sampling
- Correlation
- Probability
- Confidence intervals
- Hypothesis testing
- A/B testing

Remember that correlation does not automatically establish causation.

## 3. Python for Analytics

Learn:

- Python fundamentals
- Functions
- Lists and dictionaries
- File handling
- pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter

Typical workflow:

Load → Clean → Explore → Analyze → Visualize → Communicate

## 4. Data Cleaning

Common tasks:

- Missing values
- Duplicate records
- Invalid values
- Incorrect data types
- Outliers
- Inconsistent categories
- Date formatting
- String cleaning
- Joining datasets

Document assumptions made during cleaning.

## 5. Exploratory Data Analysis

Ask:

- What is the distribution?
- What trends exist?
- Which groups differ?
- Are there outliers?
- What variables are correlated?
- What changed over time?
- What requires further investigation?

## 6. Data Visualization

Choose charts according to the question.

Examples:

- Line chart → trends over time
- Bar chart → category comparison
- Histogram → distribution
- Scatter plot → relationship
- Box plot → spread and outliers
- Heatmap → matrix/correlation patterns

Avoid unnecessary decoration and misleading scales.

## 7. Business Intelligence

Popular tools:

- Power BI
- Tableau
- Looker Studio

Learn:

- Data connections
- Data models
- Measures
- Filters
- Slicers
- Drill-down
- Dashboard design
- KPI cards
- Scheduled refresh

## 8. Business Metrics

Examples:

- Revenue
- Profit
- Gross margin
- Conversion rate
- Customer acquisition cost
- Customer lifetime value
- Churn rate
- Retention
- Average order value

Metrics should have clear definitions.

## 9. Reporting and Communication

A strong analyst explains:

1. What happened?
2. Why might it have happened?
3. Why does it matter?
4. What should happen next?

Avoid reporting numbers without context.

## 10. Data Quality

Check:

- Completeness
- Accuracy
- Consistency
- Timeliness
- Uniqueness
- Validity

## 11. Portfolio Projects

Beginner:

1. Sales dashboard
2. Expense analysis
3. Student-performance analysis
4. Marketing campaign analysis

Intermediate:

1. E-commerce customer analysis
2. Customer churn analysis
3. HR analytics dashboard
4. Product funnel analysis

Advanced:

1. End-to-end BI dashboard
2. Automated reporting pipeline
3. Cohort and retention analysis
4. A/B test analysis
